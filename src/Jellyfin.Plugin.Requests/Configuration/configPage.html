Webhooks

Add these so changes show up immediately and deletions trigger cleanup. Seerr: Settings → Notifications → Webhook (enable all types). Radarr/Sonarr: Settings → Connect → Webhook, method POST.

Cleanup

Deletes the Seerr request (and its media record, so the title can be requested again) once the content is gone. Files in Radarr/Sonarr are never touched. Pending requests are never deleted.
